# Emne 3

Kode fra undervisningen i emne 3 og startkode til gruppeoppgaver.

## Innhold

| Mappe | Hva |
|---|---|
| `Gruppeoppgaver/Stempelkort` | Gruppeoppgave i uke 2: innkapsling. Oppgaven står i `oppgave.md`. |
| `Clicker` | Clicker med og uten klasser, fra undervisningen. |
| `RockPaperScissors` | Stein, saks, papir, fra undervisningen. |
| `Demo`, `Demo2` | Små eksempler fra undervisningen. |

## Slik kommer du i gang

1. Last ned koden på én av disse måtene:
   - **Med Git:** `git clone https://github.com/Fagskolen-GET-Academy/Emne3.git`
   - **Uten Git:** Trykk på den grønne knappen **Code** på GitHub, velg **Download ZIP**, og pakk ut mappen.
2. Åpne `Emne3.slnx` i Rider eller Visual Studio.
3. Finn prosjektet du skal jobbe med, for eksempel `Gruppeoppgaver/Stempelkort`.
4. Høyreklikk på prosjektet og velg **Run**, eller kjør det fra terminalen:
   ```
   dotnet run --project Gruppeoppgaver/Stempelkort
   ```

Startkoden kaster `NotImplementedException` til dere har implementert metodene. Det er meningen.

Du trenger .NET 10 SDK.
